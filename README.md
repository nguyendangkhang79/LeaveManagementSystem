# Hệ Thống Quản Lý Đơn Nghỉ Phép  
![Trạng thái](https://img.shields.io/badge/Trạng_thái-Đang_phát_triển-blue?style=for-the-badge)

| **Tiêu đề**               | **Nội dung**                                                                                                                                                                                                                   |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Giới thiệu**            | Hệ thống hỗ trợ nhân viên tạo và theo dõi đơn nghỉ phép, quản lý xét duyệt đơn của cấp dưới. Phát triển với **Java Servlet & JSP**, kết nối **SQL Server** qua JDBC, chạy trên **Apache Tomcat 10.1.36**, theo mô hình **MVC**. |
| **Công nghệ sử dụng**     | - Backend: Java Servlet & JSP<br>- Frontend: HTML/CSS, JSP<br>- Database: SQL Server (JDBC)<br>- Server: Apache Tomcat 10.1.36<br>- Không sử dụng: Maven, JSON                                                                   |
| **Chức năng chính**       | - Đăng nhập và phân quyền (nhân viên/quản lý)<br>- Tạo đơn nghỉ phép<br>- Xét duyệt đơn (quản lý)<br>- Xem lịch nghỉ của nhân sự (trưởng phòng)                                                                               |
| **Cấu trúc thư mục**      | ```LeaveRequestSystem/<br>├── WebContent/ # Giao diện JSP, CSS<br>├── src/ # Code Java: Controller, Model, DAO<br>├── WEB-INF/ # Cấu hình web.xml<br>├── lib/ # Thư viện JDBC```                                              |
| **Cấu trúc Database**     | ```sql<br>CREATE TABLE Users (user_id INT PRIMARY KEY IDENTITY(1,1), username VARCHAR(50) UNIQUE NOT NULL, password VARCHAR(255) NOT NULL, role VARCHAR(20) NOT NULL, department VARCHAR(50) NOT NULL);<br>CREATE TABLE LeaveRequests (request_id INT PRIMARY KEY IDENTITY(1,1), user_id INT FOREIGN KEY REFERENCES Users(user_id), from_date DATE NOT NULL, to_date DATE NOT NULL, reason TEXT NOT NULL, status VARCHAR(20) DEFAULT 'Inprogress', processed_by INT FOREIGN KEY REFERENCES Users(user_id) NULL);``` |
| **Hướng dẫn cài đặt**     | **Yêu cầu:** JDK 11+, Apache Tomcat 10.1.36, SQL Server với JDBC Driver<br>1. Tạo database `LeaveSystem` trên SQL Server, chạy SQL trên.<br>2. Cấu hình JDBC trong `DBConnection.java`:<br>```java<br>private static final String URL = "jdbc:sqlserver://localhost:1433;databaseName=LeaveSystem;encrypt=true;trustServerCertificate=true;";<br>private static final String USER = "sa";<br>private static final String PASSWORD = "yourpassword";<br>```<br>3. Copy thư mục vào `webapps` của Tomcat, khởi động và truy cập: `http://localhost:8080/LeaveRequestSystem` |
| **Hướng dẫn sử dụng**     | - Nhân viên: Tạo đơn, xem trạng thái<br>- Quản lý: Duyệt/từ chối đơn của cấp dưới<br>- Trưởng phòng: Xem lịch nghỉ nhân sự                                                                                                   |
